# Android project

See the [project README](../README.md) for installation, features, and verification.

Build with Android Studio using JDK 17 and Android SDK 35, or run `./gradlew assembleDebug` from this directory. On Windows, use `.\gradlew.bat assembleDebug`.

The generated APK is `app/build/outputs/apk/debug/app-debug.apk`. A copy is available at the repository root as [smolish-android-debug.apk](../smolish-android-debug.apk).
